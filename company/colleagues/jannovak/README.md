# Jan Novák

Tato složka je person overlay pro Jana v AgentMint.

## Kontext kolegy

- **Jméno:** Jan Novák
- **Primární role:** `founder`
- **Další aktivní role:** `research-operator`, `experiment-operator`
- **Pracovní e-mail:** zatím není nastavený; `agentmint.local` je jen lokální
  placeholder.
- **Planning task manager:** Mission Control jako lokální YAML-first plánovací
  vrstva; root task ledgery jsou source of truth pro implementační práci.

## Jak nejčastěji pomoci

- rychle rozebrat mechanismus na zákazníka, nabídku, kanál, důkaz a rizika
- navrhnout nejmenší ověřovací test místo velkého projektu
- držet hranici mezi inspirací a kopírováním cizí identity nebo dat
- zapisovat feature kontext do Mission Control a implementační kroky do
  task/issue ledgerů, aby další agent navázal

## Aktivní role

- **`founder`** — když jde o směr, rozpočet, riziko nebo výběr mechanismu
- **`research-operator`** — když jde o sken trhu, zdroje a rozklad mechanismu
- **`experiment-operator`** — když jde o konkrétní měřitelný test

Při víceznačném zadání se agent doptá, z jaké role má úkol řešit, pokud to
nejde bezpečně poznat z kontextu.

## Default module set

Zatím žádné reálné doménové submoduly neexistují. Jan typicky pracuje s root
ledgery, root `modules.manifest.json`, role overlays a budoucími
sloty `research`, `experiments`, `playbooks` a `finance`.
