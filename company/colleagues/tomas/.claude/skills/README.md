# Osobní skills — Tomáš

Tato složka drží osobní skills, které používá jen Tomáš. Sdílené týmové postupy
patří do root `.claude/skills/`.

## Kdy sem přidat skill

- Tomáš má osobní workflow, které nemá používat celý tým.
- Skill závisí na jeho lokálním nástroji nebo osobním způsobu práce.
- Skill neobsahuje secrets, tokeny ani OAuth session data.

## Kdy vytvořit sdílený skill

Pokud postup začne používat Jan, Tomáš i Petr, přesuň ho do
root `.claude/skills/` a popiš ho jako company-wide workflow.
