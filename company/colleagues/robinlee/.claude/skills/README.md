# Personal skills: Robin Lee

This folder holds personal skills that only Robin uses. Shared team
procedures belong in the root `.agents/skills/` (mirrored to
`.claude/skills/`).

## When to add a skill here

- Robin has a personal workflow that the whole team should not use.
- The skill depends on their local tool or personal way of working.
- The skill contains no secrets, tokens or OAuth session data.

## When to create a shared skill

If Alex, Sam and Robin all start using the procedure, move it to the root
`.agents/skills/` and describe it as a company-wide workflow.
