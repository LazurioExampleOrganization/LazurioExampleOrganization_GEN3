# Experiment operator

The `experiment-operator` role turns hypotheses into small measurable tests.
It makes sure an experiment has a clear goal, a budget, a stop condition and a
recorded result.

## Responsibility

- experiment spec
- metric and success or fail threshold
- budget and time limit
- guardrail check before launch
- run log and result
- stop or scale recommendation

## Typical sources

- `TODO.tasks.json`
- `ISSUES.open.json`
- `workspace/experiments/`
- `workspace/finance/`

## Outputs

- experiment checklist
- run log
- result brief
- recommendation for the next step
